# משחק טריוויה

משחק טריוויה רספונסיבי ופשוט הבנוי בעזרת HTML, CSS ו-JavaScript נקי.

## קבצים בפרויקט
* `index.html` - המבנה הראשי של המשחק.
* `style.css` - עיצוב האתר והכפתורים.
* `script.js` - לוגיקת המשחק ומאגר השאלות.

## איך להפעיל
פשוט הורידו את הקבצים ופתחו את הקובץ `index.html` בדפדפן שלכם.
